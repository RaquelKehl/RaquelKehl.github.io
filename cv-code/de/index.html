Kompilierte Ausgabe

cv-master.yaml → Build → A4-PDF

So funktioniert es
  • Quelle: ein privates cv-master.yaml
  • Templates: HTML, nur Struktur — kein Text
  • Render: Headless Chromium → A4-PDF
  • QA-Gate: Seitengeometrie, ATS-Textlayer, Sichtprüfung, Fidelity-Diff auf Wortebene
Warum ein kuratierter Auszug

Dieser Block wird beim Build als reines HTML gerendert — dahinter liegt keine öffentliche YAML-Datei, und hier steht nichts, was nicht ohnehin auf dieser Website öffentlich ist. Der vollständige Datensatz mit der ganzen beruflichen Historie bleibt im privaten Repository und kompiliert in die massgeschneiderten CVs, die pro Bewerbung geteilt werden.

Warum CV as Code

Ein CV ist Daten mit Meinungen zur Darstellung. Liegt der Inhalt in einer einzigen, geprüften Quelle, trägt jedes Artefakt — DE oder EN, Governance- oder Delivery-Fokus — dieselben verifizierten Fakten, und eine diffbare Pipeline fängt Abweichungen so, wie Code-Review Bugs fängt.
