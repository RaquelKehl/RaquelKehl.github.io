How it works
  • Source: one private cv-master.yaml
  • Templates: HTML, structure only — no text
  • Render: headless Chromium → A4 PDF
  • QA gate: page geometry, ATS text layer, visual review, word-level fidelity diff
Why a curated excerpt

This block is rendered to plain HTML at build time — there is no public YAML file behind it, and nothing here that isn’t already on this site. The complete record, with full employment history, stays in the private repository and compiles into the tailored CVs shared per application.

Why CV as code

A CV is data with opinions about presentation. Keeping the data in one reviewed source means every artefact — DE or EN, governance or delivery focus — carries the same verified facts, and a diffable pipeline catches drift the way code review catches bugs.
